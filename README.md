# Sistema de Nómina SOLID

Proyecto desarrollado en Java para la gestión y cálculo de nómina de diferentes tipos de empleados.

## Tipos de empleados

- Empleado asalariado
- Empleado por horas
- Empleado por comisión
- Empleado temporal

## Características

- Programación orientada a objetos
- Herencia
- Polimorfismo
- Encapsulamiento
- Principios SOLID
- Código limpio
- Validaciones
- Pruebas
- Control de versiones con GitHub

## Tecnologías

- Java
- NetBeans
- Git
- GitHub
